# ☕ Coffee Culture — Premium Frontend Experience

A visually immersive, high-end coffee website built with pure HTML, CSS, and JavaScript.
This project focuses on crafting a **luxury UI/UX experience** with smooth animations, interactive elements, and modern design principles.

---

## ✨ Live Concept

> “Where Coffee Becomes Culture” — a digital experience that blends aesthetics with interaction.

---

## 🚀 Features

* 🎯 **Fully Responsive Premium UI**
* 🖱️ **Custom Cursor & Micro-interactions**
* 🎬 **Smooth Scroll & Reveal Animations**
* 🎨 **Canvas-based Hero Animations**
* ☕ **Interactive Menu System**

  * Category filtering (Hot / Cold / Signature)
  * Dynamic product cards
  * Modal preview for each item
* 🧾 **Custom Order Builder**

  * Select drink, size, and extras
  * Real-time price calculation
* 💡 **Modern Design System**

  * Glassmorphism + soft glow aesthetics
  * Elegant typography & spacing
* ⚡ **Zero Frameworks**

  * Built using Vanilla JavaScript (no libraries)

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 (Advanced styling & animations)**
* **JavaScript (DOM + Canvas API)**

---

## 📌 Project Status

> 🚧 This is a **frontend prototype**

* No authentication system
* No backend or database integration
* Order functionality is UI-based (not connected to real orders)
